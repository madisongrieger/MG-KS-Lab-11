# Problem 1
Write a function, string_to_char_dict, that takes a string of text and returns a dictionary mapping each unique character to the number of times it appears.

# Problem 2
Using string_to_char_dict, write a function, is_unique, which determines if a string has all unique characters.  

# Problem 3

# Problem 4

# Problem 5
